================================================================================
  คู่มือการติดตั้งและใช้งาน Prosoft Auto Login & Fill (Standalone Portable)
================================================================================

คุณสมบัติ:
- ไม่จำเป็นต้องติดตั้ง .NET Runtime หรือโปรแกรมเสริมใดๆ (ทำงานได้ทันทีบน Windows 10/11 64-bit)
- เป็นแบบ Portable สามารถวางไว้ที่ใดก็ได้ในเครื่อง เช่น C:\ProsoftAutoLogin หรือโฟลเดอร์บน Desktop

--------------------------------------------------------------------------------
ขั้นตอนการติดตั้งบนเครื่องใหม่:
--------------------------------------------------------------------------------
1. แตกไฟล์ ZIP (ProsoftAutoLogin-Portable.zip) ไว้ที่โฟลเดอร์ที่ต้องการ เช่น:
   C:\ProsoftAutoLogin
   หรือโฟลเดอร์บนหน้า Desktop

2. (ทางเลือก) ดับเบิ้ลคลิกไฟล์ "Install-Desktop-Shortcut.bat"
   เพื่อสร้างไอคอนทางลัดไว้บนหน้าจอ Desktop สำหรับเปิดใช้งานครั้งต่อไปได้สะดวก

--------------------------------------------------------------------------------
ขั้นตอนการใช้งาน:
--------------------------------------------------------------------------------
1. เปิดไฟล์ข้อมูล:
   input\input.csv
   (สามารถเปิดแก้ไขด้วย Microsoft Excel หรือ Notepad)
   - กรอกข้อมูลเอกสารและสินค้า
   - กำหนดคอลัมน์ "status" เป็น "Approved" สำหรับแถวที่ต้องการให้ระบบนำไปบันทึก
   - แถวที่ไม่มีสถานะ Approved ระบบจะข้ามโดยอัตโนมัติ
   - บันทึกไฟล์ (หากใช้ Excel ให้ Save as CSV UTF-8)

2. เปิดโปรแกรม Prosoft myAccount และเข้าสู่ระบบ (Login) ให้เรียบร้อย

3. เปิดหน้าต่าง "ซื้อเชื่อ" (Credit Purchase) ไว้ใน Prosoft

4. ดับเบิ้ลคลิกเปิดโปรแกรม:
   ProsoftAutoLogin.exe (หรือ RUN.bat)

5. ในหน้าต่างโปรแกรม:
   - กดปุ่ม "กรอกผู้ขายจาก CSV"
   - ระบบจะตรวจจับหน้าต่างซื้อเชื่ออัตโนมัติ
   - ทำการวนลูปสร้างเอกสารใหม่ กรอกผู้ขาย กรอกสินค้า กำหนดแผนก INTER และบันทึกข้อมูลทุกรายการที่ status=Approved จนเสร็จสมบูรณ์
